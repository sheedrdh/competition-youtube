# Landing Page YouTube Challenge 2026

Template Vite + Tailwind pour promouvoir une chaîne YouTube hi-tech et sa vidéo principale.

## Commandes

```bash
npm install
npm run dev
npm run build
```

## A remplacer

- `CHANNEL NAME`
- `VIDEO_ID` dans l'embed YouTube
- le lien de chaîne YouTube
- le produit, l'usage ou la tendance hi-tech de la vidéo principale
- la cible, la ligne éditoriale et les détails des shorts

Le fichier `landing-page.html` d'origine est conservé comme référence.
